Self-hosted · open source · MIT{version} · tested on a real collection

Don't just manage your collection. Work with it.

Brick Work keeps your sets, minifigures, parts and boxes in one place, then helps you use them: check a set's parts, pull the missing ones from loose stock, and see which unfinished sets that stock can complete.

Install Brick WorkTry the demoView on GitHub

The demo runs the real interface on an invented collection around seven real sets; nothing is saved. The set pictures are Rebrickable's and an item without one shows a plain tile; a real install loads pictures from BrickLink and Rebrickable (how pictures work).

Install

Running in about five minutes.

Docker Compose on your own machine pulls the published image for amd64 and arm64. Then open it in the browser.

git clone --branch v{version} https://github.com/{repository}.git && cd brick-work
mkdir -p data && sudo chown 1000:1000 data
cp .env.sample data/.env # set BW_AUTHENTICATION_PASSWORD
docker compose pull
docker compose up -d

Then open http://localhost:3333 and sign in with your password. Brick Work is for one user on a home network or a VPN, not the open internet.

No server and no Git: about 15 minutes and a few GB of disk space. Tested on macOS; the Windows steps are the same, typed in PowerShell, but no test on a real Windows computer is recorded yet.
