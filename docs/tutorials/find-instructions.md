# Find the instructions for a set

You own a set but have no instruction booklet for it in Brick Work. In this tutorial you open the set's instructions page, download the PDF there, and attach it to the set.

It takes about 5 minutes. You need a Brick Work install with at least one set in your collection. Every number and name comes from an invented collection, so yours will differ.

Brick Work downloads nothing itself. It gives you the links; you download the PDF in your browser and upload it here.

## 1. Open Find instructions

1. Open **Tools & Admin → Instruction files** and select **Find instructions**. You can also open it from the **Instructions & Box** tab of one set.
2. Read the line under the heading. It says how many sets have no booklet, for example *4 sets have no booklet*.
3. Check **Region for official instructions**. The official files differ per region. It starts from your retail country in **Tools & Admin → Settings**.

The list **Sets without a booklet** shows every set in your collection that has no PDF, with its picture, number, name, theme and year.

## 2. Open a set's instructions page

Each row has two links. Both open in a new tab.

- **Official instructions** opens the set's instructions page on lego.com for your region.
- **Rebrickable** opens the set's page on Rebrickable.

A promotional set with a number such as `COMCON034-1` has no official page, so its row shows the Rebrickable link only.

Download the PDF on that page. Brick Work does not look at the page and does not fetch anything for you.

## 3. Upload the PDF

1. Back on **Find instructions**, select **Upload a PDF** in the set's row. The **Instruction files** page opens with the set's number filled in.
2. Check the **File label**. **Instructions** is the default.
3. Choose the PDF you downloaded and select **Attach PDF**. A file can be up to 20 MB.

The PDF appears under the set on the **Instructions & Box** tab. The set leaves the list **Sets without a booklet**.

## 4. Look up a set that is not in the list

To get the links for a set you do not own yet, type its number into **Set number**, for example `6081-1`, and press Enter. The page shows the same two links for that number. Change the region and the links follow.
