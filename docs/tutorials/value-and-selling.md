# Keep it or part it out

You own a used set and wonder whether it is worth more intact or as loose parts. In this tutorial you read what the set is worth and compare that with its part-out value. Then you let the Sell card suggest an asking price and write the listing text.

It takes about 15 minutes. You need a Brick Work install with a set you own, preferably one you have already [checked part by part](first-set.md), and a BrickLink key under **Tools & Admin → Catalogues & keys**. Prices come from BrickLink, so without the key you only see prices already stored. Your own numbers and names will differ from the examples.

## 1. Open the set and read its prices

1. Open **Collection → Sets** and select the copy you are weighing up. If the set has several copies, select the one you mean on the page.
2. Find the **Prices** card. It lists **Used** and **New**: BrickLink's sold average for the set, with the number of sales and the age of the quote.
3. Select **Update price** if the figures look old. It queues a fresh quote for this set and the card updates when it arrives.

The set's own price tells you what the set sells for as a whole. It does not tell you yet what the parts are worth one by one.

## 2. Read the part-out value

1. On the same **Prices** card, find **Parted out**, below **Used** and **New**. The amount after the ≈ sign is what all the parts and figures of the copy fetch when sold one at a time.
2. Read the line under it. It shows the complete value, the as is value of your copy and how many lines have a price, for example *prices for 54 of 54 lines*. Brick Work only shows a total when at least 90 % of the lines have a price.
3. Check the age at the end of the line. The total carries the date of its oldest price. A price past its age limit still counts, but the line says **stale**.
4. If **Parted out** says **Not enough prices yet**, select **Fetch part prices**. It asks BrickLink for the parts that have no price. The button is greyed out without a BrickLink key.

Each request fetches up to 200 items. If more remain, the status says how many, and the button stays so you can run it again. A part nobody has sold lately ends up as **parts have no sales yet**, and the total may stay hidden.

## 3. See whether parting out beats keeping the set

1. Look for the line **Parting out is worth** followed by an amount and **more**. It appears under **Parted out** only when the parts clearly beat what the copy is worth now.
2. If that line is missing, parting out does not clearly win. Keep the set intact, or part it out only if you have another reason to.
3. Open **Planning → Complete sets** to see the same figure for every copy with a gap. Each copy has a **Parted out ≈** line with the same count of priced lines.
4. In **Sort**, choose **Part-out value**. The copies with the highest total come first. Copies with no total come last. If no copy has a total, the list keeps its number order and points you to **Fetch part prices** on a set page.

Two cases show no comparison. A part list priced in another currency than your set prices says so instead. A copy without a part list has no **Parted out** row at all.

## 4. Read what the copy is worth to you

1. Back on the set page, find the **Value** card for the selected copy. **Paid** is your price paid and **Worth now** is what the copy is worth today.
2. Read the line under **Worth now**. It names the source: your own **Estimate** from the edit sheet, or the sold average of the set. A copy you have checked has its missing parts taken off one by one.
3. Read **Gain** or **Loss**. It is written in words, with the amount and the percentage.

Set the part-out figure next to **Worth now**. If parting out is higher by more than the effort and the fees are worth to you, parting out wins. If it is close, keeping the set costs you nothing.

## 5. Prepare a sale with the Sell card

The **Sell this copy** card sits between **Prices** and **Value**. It changes nothing in your collection. It only suggests a price and writes text.

1. Read the pills at the top. They show the condition and whether the copy is **Complete**, **Incomplete** or **Not checked**. If it says **Not checked**, select **Check this copy** and work through the check first. A sealed copy needs no check.
2. Read **Asking price**. The card starts from the used sold average for this condition, or the new average for a new or sealed copy. It then takes off the used price of each missing part and figure.
3. Open **Missing parts** and **Missing figures** to see each line: colour, name, part number and price. A line with no fresh price is a dashed row marked **needs evidence**. It is left out of the sum.
4. Read the last row of the sum. If the deductions would take the price below the part-out value of what is present, the card uses that value as the asking price and says so. Parting out is then the floor you never sell under.
5. If the card shows **no sales** and no asking price, select **Update price** or add the missing rate in Settings. Until then **Copy listing text** stays off.

Damaged parts are not taken off the price, but the card and the listing name them. Your own **Estimate** is ignored here. The card shows the market price, not your opinion.

## 6. Write and copy the listing

1. Select **Preview**. On a wide screen a panel opens at the side. On a phone it is a sheet. The **Listing text** names the set, the condition and how complete it is. It lists the missing parts by category and the figures, says whether the box and instructions are there, and ends with the asking price.
2. Edit the text as you like. To leave the price out, delete the last line. **Reset to generated** brings the first text back.
3. Select **Copy listing text**. The status says **Copied**. If your browser refuses, the text stays selected so you can copy it by hand.
4. Select **Close**, then paste the text into your listing.

Brick Work does not post the sale or change the copy. When the set is sold, record that on the copy yourself.
