Coming from BrickLink.

Download a wanted list or a store inventory as an XML file and read it in. The review asks, row by row, whether a line is owned, loose or a wish.

Wanted listInventory XMLReviewed row by row

How to bring it in

  1. 1
    Download the XMLA wanted list or a store inventory from BrickLink.
  2. 2
    Choose an XML fileIt opens Add with File selected. Brick Work reads item type, number, colour, quantity and condition.
  3. 3
    Review each lineOwned, loose or a wish. A wanted list also brings its maximum price, remarks and list name.
Read the full guideInstall first
LimitsA file can be up to 2 MB and one review shows up to 500 rows. Lines Brick Work cannot match are listed and left out.
