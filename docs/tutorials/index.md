# Tutorials

Learning by doing: one complete path through the app, start to finish.

Each tutorial is one path you follow from the first step to the last. A fresh install opens **Get started**, a guided first run, and the [README](https://github.com/Ulef1005/brick-work#standalone-installation-with-docker) has the install steps. For a single task, use the [how-to guides](../how-to/index.md).

- [Build from your bulk](build-from-your-bulk.md): give loose parts a drawer, pick the missing parts of several sets in one pass, and see which sets your loose stock finishes.
- [Script your collection](script-your-collection.md): create an API token, read and change the collection from the command line, and connect an assistant.
