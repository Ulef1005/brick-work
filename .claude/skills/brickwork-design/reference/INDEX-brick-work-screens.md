# Brick Work screens: index

Handbook structure: one **Guide** page and one page per main nav group. Every workflow shows all sizes in one row: phone 390, MacBook 1440 (and 1280 checker), iPad mini portrait 768 and landscape 1024. Dark is switched with the **Theme** tweak on each page (frames set their own mode, so forcing dark from outside has no effect). Tokens: `tokens-v2.css`. PNG exports: `frames/`.

Devices: MacBook 2020 main (1440 × 900, 1280 × 800); iPad mini 5 sometimes; iPhone 16 very rarely.
