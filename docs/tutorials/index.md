# Tutorials

Learning by doing: one complete path through the app, start to finish. Each step says what you do and what you see. For detail and variants, follow the links to the [how-to guides](../how-to/index.md).

- [Your first set, start to finish](first-set.md): install, load the catalogue, add one set, check its parts and see where the gaps show up.
- [Finish a half-built set](finish-a-half-built-set.md): check a half-built copy, put the missing parts on a wishlist, receive the order and watch the copy turn complete.
- [Build from your bulk](build-from-your-bulk.md): give loose parts a drawer, pick the missing parts of several sets in one pass, and see which sets your loose stock finishes.
- [Script your collection](script-your-collection.md): create an API token, read and change the collection from the command line, and connect an assistant.
