12oScan a set barcode
Add (4d) gets a barcode scanner. Phone: the camera reads the EAN on the box, a sheet shows the matching set with a condition selector (Sealed, New, Used), copies, storage and price paid, then adds it; Keep scanning returns to the camera with an Undo toast. Desktop and iPad: camera or USB scanner into one field, a session list with condition per set, and one add for all. Barcodes are looked up on Brickset with the configured key.
