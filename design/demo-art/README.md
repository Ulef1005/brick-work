# Demo illustrations

Original black-and-white line drawings for the invented collection of the demo (`brickwork/demo/showcase.py`) and for the README and Pages pictures: a brick-built scene for each set, a generic figure for each minifigure, an object for each gear, book and catalog, and a flat drawing of the part's shape for each part (one drawing per shape: the part's colour is shown by the app's own colour chip and name).

They are drawn from shapes by [`scripts/demo_art.py`](../../scripts/demo_art.py) with Pillow, deterministically: a near-black line (#1A1816) on an opaque white card, light grey shading where it helps, no colour and no shadows. The white card reads on the light and on the dark theme. **Nothing is taken from, traced from or derived from BrickLink, Rebrickable, Brickset or LEGO pictures.** They are original artwork made for this project, MIT as the project (see [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md)).

`manifest.json` maps `<namespace>/<number>[/<colour>]` (the catalogue's own keys: `sets/99101-1`, `minifigs/fig-990001`, `parts/3001/5`) to a file; a drawing that several items share is one file (`art-<hash>.png`). The demo world stores each one through the app's own `picture` table (source *Demo illustration*) under `data/images/` in its media folder, so the app shows it like any picture. Regenerate with `python scripts/demo_art.py`; `python scripts/demo_art.py --check` fails when the world needs a picture the manifest lacks.
