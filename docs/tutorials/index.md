# Tutorials

Learning by doing: one complete path through the app, start to finish.

There is no tutorial yet. To start, follow the install steps in the [README](https://github.com/Ulef1005/brick-work#standalone-installation-with-docker). A fresh install opens **Get started**, a guided first run: load the catalogue, set up keys (optional), bring your collection in and see how the inventory works. Then use the [how-to guides](../how-to/index.md).
