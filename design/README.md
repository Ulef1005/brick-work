# Design frames

The approved Brick Work design, kit v1.2: 200 frames, each exported in a light and a dark theme (400 PNG files).

The folders follow the app's navigation:

| Folder | Contents |
|---|---|
| `guide/` | Principles, colour, tokens and type, navigation, the data-type key |
| `shell/` | Desktop rail and top bar, phone bars and sheets, system pages (404, error, success, lightbox) |
| `collection/` | `sets/`, `minifigures/`, `parts/`, `instructions/`, `boxes/` |
| `workbench/` | `part-to-inventory/`, `check-set-parts/`, `part-picker/`, `matcher/`, `orders/`, `storage/` |
| `planning/` | `wishlist/`, `prices/`, `complete-sets/` |
| `manage/` | `add/`, `tools-and-admin/` (with `statistics/`) |

Check Set Parts is opened from a set rather than from the navigation. It sits under `workbench/` because it is a Workbench tool.

File names: `<section>-<frame>-<width or device>-<theme>.png`. The section id (for example `3e`) matches the section in the kit's `BW *.dc.html` pages.

The frames show synthetic sample data.
