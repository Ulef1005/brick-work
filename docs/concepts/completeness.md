# Completeness

*Since 0.5.0.*

**What it means.** Whether one copy of a set has everything it should: *Complete*, *Incomplete*, *Sealed* (never opened), or *Not checked* when nothing is recorded yet.

**Roughly how it is calculated.** You can choose the value yourself, or let Brick Work work it out. Worked out, a copy is Complete once it is marked "Set is checked" and none of its parts or minifigures is missing or damaged; otherwise it is Incomplete. Spare parts and the parts inside its minifigures do not count, but a missing whole minifigure does.

**How to read it.** It is about this copy, not the set: two copies of the same set can differ. Incomplete with no missing parts usually means the copy has not been checked to the end yet.

**What changes it.** Finishing Check Set Parts, marking parts or minifigures missing or damaged, allocating a part from an order or loose stock to the copy, or ticking "Set is checked". A value you chose yourself stays as chosen until you change it.
