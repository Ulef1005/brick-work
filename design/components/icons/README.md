# Brick Work UI icons

24 px grid, 1.6 px stroke, round caps and joins, `currentColor`. One file per icon plus `sprite.svg` (symbols `bw-<name>`). Where the Toni kit already has the icon (search, chevron-right, back, close), use the Toni one and drop ours. The remaining names are new for Brick Work. The Toni kit's `icons-admin` folder was not available in the design session; check it for further overlaps (the fork maps about 100 Remix names to the Toni set) before shipping.
