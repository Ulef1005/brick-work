Install Brick Work in about five minutes.

It runs in a container on your own computer or server. Your data stays in one folder you back up.

Docker Compose

Pulls the published image for amd64 and arm64. Then open it in the browser.

git clone --branch v{version} https://github.com/{repository}.git && cd brick-work
mkdir -p data && sudo chown 1000:1000 data
cp .env.sample data/.env # set BW_AUTHENTICATION_PASSWORD
docker compose pull
docker compose up -d

Then open http://localhost:3333 and sign in with your password.

Single user, home networkBrick Work is meant for a home network or a VPN, not the open internet. Without a password the server refuses to start, because anyone who can reach it could edit the collection.
No server, no Git

Docker Desktop on Windows or Mac

About 15 minutes and a few GB of disk space. Tested on macOS; the Windows steps are the same, typed in PowerShell, but no test on a real Windows computer is recorded yet.

On your NAS or home server

Pick your system and follow its guide.

Unraid

Install it from Community Applications and set a password; the template sets the user to 99:100, the ids Unraid gives a shared folder. Not yet tested on a real device.

Unraid guide

Synology Container Manager

Paste one compose file into Synology Container Manager and set a password. No Git, no ownership change. Not yet tested on a real device.

NAS and Portainer guide

Portainer

Paste one compose file into a Portainer stack and set a password. No Git, no ownership change. Not yet tested on a real device.

NAS and Portainer guide

With Synology Container Manager or Portainer: To keep the data in a shared folder, set the user to the folder owner's ids. Put the pictures on the NAS with BW_MEDIA_PATH and keep the database on fast local storage.
