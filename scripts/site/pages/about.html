About Brick Work

A free, open-source web app for private collectors, built and used by one person. Its maintainer uses it daily on a real collection of set copies.

Who builds it

Ulf Weihbold, Linz. One maintainer, one collection, a home-screen app on the phone and a desktop app.

Licence

MIT. The source, issues and releases are on GitHub.

View on GitHub

Your data

Self-hosted, in one folder you back up. No account, no telemetry. Everything that needs no catalogue key works offline.
