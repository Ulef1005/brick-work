The workbench for your brick collection.

Every app does inventory. Brick Work also helps at the table: check a set's parts, pull the missing ones from your loose stock, and see which unfinished sets that stock can complete.

Pre-1.0 and used daily by its maintainer. Your data stays on your machine; there is no account and no telemetry.

Why Brick Work

Made for the work at the table

Check Set Parts, Part Picker and Matcher turn the inventory into progress: "142 of 380", the parts to pull, the sets you can finish.

See the workflows

Everything is an item

Sets, minifigures, loose parts, instructions and boxes share the same modules: notes, storage location, prices, history and Undo.

Yours

Self-hosted with Docker Compose. Your database and photos live in one folder you back up. Catalogue data comes from your own BrickLink, Rebrickable and Brickset keys.

Install it

Installable on any screen

A web app you add to the Home Screen from the browser, with no app store: iPhone and iPad in Safari, desktop in a Chromium browser. It needs HTTPS to install.

Scriptable

A versioned REST API over the whole collection with scoped tokens, an OpenAPI contract, idempotent writes and an audit event with an Undo link for every change, plus an admin CLI.

API reference

Ready for AI assistants

A built-in MCP server lets an assistant read your collection and, only if you allow it, change it. It uses the same API, scopes and Undo as any other client.

MCP guide

Three flows that finish sets

  1. Check Set PartsPick a copy, go through its parts against the inventory and keep a running count of what is missing.
  2. Part PickerTick several sets and get the missing parts you can pull from your sorted loose stock, in your own sort order.
  3. MatcherSee which incomplete copies your loose stock can finish, then decide what to build or buy.

How each flow works · Use cases

Made for scripts and assistants

Create a scoped token, call the API, or connect an assistant over MCP. Write tools are off unless you enable them.

docker compose exec brickwork brickwork token create --name assistant --scope read
brickwork mcp --in-process --token-file data/mcp-token

API reference · MCP guide

Start in five commands

mkdir -p data && sudo chown 1000:1000 data
cp .env.sample data/.env   # set BW_AUTHENTICATION_PASSWORD
docker compose build
docker compose run --rm --entrypoint brickwork brickwork setup
docker compose up -d

Then open http://localhost:3333. Moving an old collection over? brickwork migrate imports it read-only. The full guide is in the documentation.
