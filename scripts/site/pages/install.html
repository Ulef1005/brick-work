Install Brick Work in about five minutes.

It runs in a container on your own computer or server. Your data stays in one folder you back up.

Docker Compose

Pulls the published image for amd64 and arm64. Then open it in the browser.

git clone --branch v{version} https://github.com/{repository}.git && cd brick-work
mkdir -p data && sudo chown 1000:1000 data
cp .env.sample data/.env # set BW_AUTHENTICATION_PASSWORD
docker compose pull
docker compose up -d

Then open http://localhost:3333 and sign in with your password.

Single user, home networkBrick Work is meant for a home network or a VPN, not the open internet. Without a password the server refuses to start, because anyone who can reach it could edit the collection.
No server, no Git

Unraid

Run the same image and set the user to 99:100, the ids Unraid gives a shared folder.

NAS

If the shared folder is not owned by uid 1000, set the user to the folder owner's ids instead of changing ownership. Put the pictures on the NAS with BW_MEDIA_PATH and keep the database on fast local storage.
