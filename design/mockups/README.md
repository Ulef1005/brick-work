# Mock-ups

Brick Work's black-and-white wireframes (design builder, step 2): one per function and state, Balsamiq style, built on the neutral base only (no brand, no colour, no logo). Approved by Ulf as the UX concept; each has its line in [../APPROVALS.md](../APPROVALS.md). Generated by `design/sources/n/wf_frames.py` (`build`, `check`); content in [brackets] is synthetic.

Brick Work predates the standard: its shipped screens have no wireframes. The first set is the Sync tool of milestone N (commission N, #517), the model every site page follows.
